# MATRIZ DE EQUIVALENCIA FUNCIONAL — Paperclip vs TokenizAi V2

## Formato de Classificação

| Situação | Significado |
|---|---|
| **IMPLEMENTADO** | Funciona de ponta a ponta, com evidência reproduzível de extremidade a extremidade |
| **PARCIAL** | Existe, mas faltam partes essenciais para fluxo completo |
| **APENAS VISUAL** | Existe interface sem operação real; retorno screen/mock/simulado |
| **BACKEND SEM FRONTEND** | A operação existe no backend, mas não está disponível adequadamente na interface |
| **FRONTEND SEM BACKEND** | A interface existe, mas não possui operação funcional no backend |
| **AUSENTE** | Não existe implementação; referência apenas em documentação desatualizada |
| **BLOQUEADO POR HERMES** | Depende de capacidade que o runtime Hermes não oferece (CLI-only, endpoints faltando) |
| **NÃO COMPROVADO** | Não foi possível verificar devido a limitações de acesso ou dados |
