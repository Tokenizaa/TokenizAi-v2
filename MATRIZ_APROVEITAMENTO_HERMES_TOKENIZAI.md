# Matriz de Aproveitamento Hermes × TokenizAi V2

## Formato de Classificação

| Situação | Significado |
|---|---|
| **REUTILIZAR HERMES** | Recurso nativo do Hermes; TokenizAi deve consumir via API/UI sem recriação |
| **CORRIGIR INTEGRAÇÃO EXISTENTE** | Recurso existe no Hermes e na TokenizAi, mas integração (parser, endpoint, UI) está quebrada | 
| **REAPROVEITAR E COMPLEMENTAR TOKENIZAI** | Recurso Hermes não cobre necessidade empresarial; TokenizAi deve implementar própria camada |
| **IMPLEMENTAR CAMADA EMPRESARIAL TOKENIZAI** | Hermes não tem recurso equivalente; TokenizAi deve criar nova tabela/endpoint/API |
| **BLOQUEADO POR CAPACIDADE NÃO DISPONÍVEL** | Hermes não oferece recurso e não há como estender via CLI/API atual |
| **NÃO COMPROVADO** | Não foi possível verificar devido a limitações de acesso ou dados |
